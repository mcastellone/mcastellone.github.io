## Original Artifacts

The Travlr full-stack web application is my selected artifact for the Software Engineering and Design category. I originally developed this application in CS 465 Full Stack Development using Node.js, Express, MongoDB, Mongoose, Angular, and REST APIs. I selected Travlr because it demonstrates my ability to work with multiple components of a full-stack application and improve an existing software design.

For CS 499, I enhanced the original Travlr application to improve its security, validation, error handling, organization, and maintainability. The enhancement included strengthening authentication and authorization for administrative functions, adding server-side validation, improving error handling, reducing duplicated logic, and improving the separation of responsibilities within the application.

These changes demonstrate my ability to evaluate an existing software application, identify areas for improvement, and implement changes without removing the application's existing functionality. The enhancement also demonstrates secure coding practices and my understanding of how the frontend, backend, API, authentication system, and database interact within a full-stack application.

### Enhancement Summary

For CS 499, I enhanced the Treasure Hunt intelligent agent to demonstrate my growth in algorithms and data structures. The enhanced version improves the deep Q-learning process through valid-action selection, bounded experience replay, a target network, controlled epsilon decay, reproducibility settings, bounded episode lengths, and performance tracking for loss, win rate, epsilon, and steps.

These enhancements make the agent's learning process more organized and measurable while demonstrating algorithmic decision-making, reinforcement learning, and the purposeful use of data structures.
