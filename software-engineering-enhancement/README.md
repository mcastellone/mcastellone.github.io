# Software Engineering and Design Enhancement

This folder contains the enhanced version of my Travlr full-stack web application completed for CS 499.

The enhancement focuses on improving the application's software design, security, validation, error handling, organization, and maintainability while preserving the functionality of the original application.

## Key Enhancements

- Improved authentication and authorization
- Added server-side validation
- Improved error handling
- Strengthened separation of concerns
- Reduced duplicated logic
- Improved secure coding practices
- Improved maintainability of the application

The original Travlr source code is available in the root of this repository for comparison with the enhanced version.
